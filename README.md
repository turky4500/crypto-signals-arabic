# مراقب إشارات العملات الرقمية — Crypto Signals (Arabic)

منصة عربية آلية لمراقبة **إشارات شراء (Spot / USDT / فريم 1H)** على Binance،
وإرسال توصية جاهزة (دخول / وقف / هدف) إلى المشتركين عبر **تلغرام**، مع تتبّع
نتيجة كل توصية وعرضها في لوحة ويب عربية (GitHub Pages).

> تنبيه: النظام **إشاري وتحليلي فقط** ولا ينفّذ صفقات ولا يدير محافظ.
> النتائج التاريخية لا تضمن نتائج مستقبلية.

## كيف يعمل

```
Google Apps Script (كل 5 دقائق) ──► workflow_dispatch
        ↳ احتياط: cron في GitHub
.github/workflows/monitor.yml
   1. مزامنة main  →  2. تخطّي إن كانت الجولة حديثة (< 270 ثانية)
   3. Binance public API: كل أزواج USDT Spot بسيولة ≥ 100k$
   4. لكل عملة: شموع 1H مغلقة → Supertrend + AI Reader + 6 مؤشرات
   5. كشف BUY → بوّابة الجودة → فلتر الزخم (H4/H1/D1) → اتفاق المؤشرات
   6. منع التكرار + توصية واحدة مفتوحة لكل عملة
   7. Entry/SL/TP بدقة tickSize، R:R = 2
   8. تلغرام: إشارة + حسم + لمسة وقف + تقرير يومي/أسبوعي
   9. حفظ data/*.json + نشر الموقع
```

## البنية

| المسار | الدور |
|---|---|
| `src/binance/` | عميل REST عام (إعادة محاولة، تقريب الأسعار) |
| `src/indicators/` | Supertrend، AI Market Reader (k-NN)، Ichimoku، MACD/RSI/BB، DMI |
| `src/engine/` | المنسّق `monitor.py`، `detector.py`، `quality_gate.py`، فلتر الزخم، الأداء |
| `src/notify/` | تلغرام/واتساب، صياغة الرسائل، التقارير، الأحكام الشرعية |
| `web/` | لوحة ثابتة تقرأ `data/*.json` |
| `research/` | دراسة جودة التوصيات + محرّك باك-تست على OHLCV |
| `data/` | حالة التشغيل والإشارات والإحصاءات (تُحدَّث كل جولة) |

## بوّابة الجودة (Quality Gate)

قرار النشر لم يبقَ معتمدًا على فلتر الزخم وحده. دراسة `research/live_study.py`
على نتائج حقيقية مسجّلة (377 إشارة منشورة على 50 يومًا + 3,870 إشارة مرشّحة
محسومة) أظهرت أن **مصدر الإشارة** هو أقوى فاصل في الجودة:

| المصدر | المنشور (50 يومًا) | المرشّحات (10 أيام) |
|---|---|---|
| supertrend وحده | 8.1% (211) | 16.5% (976) |
| ai | 22.0% (150) | 23.3% (447) |
| strong (ai + st) | 12.5% (16) | 23.4% (47) |

الأثر المقاس آنذاك: نسبة نجاح الإشارات المنشورة من 13.8% إلى 21.1% مع خفض
الحجم ~56%.

**تحديث 2026-11-02 (باك-تست السوق):** باك-تست على 198 زوجًا × 120 يومًا
(9,971 إشارة، تقسيم زمني 70/30) أظهر أن شرط "المصدر ai" لم يعد الأفضل بعد
تغيير هدف الربح وشرط الدخول. الوضع الحالي:

| القرار | القيمة | الدليل خارج العينة |
|---|---|---|
| هدف الربح | 1R (كان 2R) | −0.072R مقابل −0.204R |
| شرط الدخول | RSI(1H) < 50 (كان <70 مع ملاحقة زخم 2.25%) | +0.140R، موجب في النصفين |
| شرط المصدر | أُلغي؛ الثقة ≥0.60 تبقى | supertrend مع شرط RSI = +0.128R |
| القاعدة كاملة | RSI<50 + ثقة ≥0.60 + 1R | 164 صفقة، 59.4% نجاح، EV +0.166R، PF 1.42 |

التفاصيل والجداول والقيود: `research/results/backtest_report.md`، والبيانات
الخام: `research/results/backtest_summary.json`.

الإعدادات كلها تحت `quality_gate` في `src/config/settings.py` أو
`data/settings.json`، وكل قرار (سبب الحجب + القياسات) يُسجَّل مع المرشّح في
`data/candidate_study.json` لمواصلة القياس خارج العينة.

## البحث والباك-تست

```bash
# دراسة النتائج المسجّلة (لا تحتاج شبكة)
python -m research.live_study          # → research/results/live_study.{md,json}

# باك-تست كامل على بيانات السوق (يحتاج اتصالًا بـ Binance)
python -m research.backtest --symbols 250 --candles 3500
```

`research/backtest.py` يعيد بناء الإشارات شمعة بشمعة، ويجرّب 15 بديل خروج
(هدف 0.75R…3R، وقف بالإغلاق أو باللمسة، مهلة 24/72 ساعة/7 أيام، نقل التعادل)
مع تقسيم زمني تدريب/اختبار 70/30، ويحسب فواصل ثقة (Wilson للنجاح، bootstrap
لـ EV) و46 شريحة دخول. خيار `--end-ms` يثبّت نهاية البيانات لنتيجة قابلة
للتكرار.

> لتشغيله حيث لا يوجد اتصال بـ Binance: أضف ملف العلامة `research/.run_backtest`
> ثم ادفع — يشغّله `tests/test_ci_backtest.py` داخل GitHub Actions وينقل
> الملخص المضغوط عبر annotations (بلا حاجة لصلاحية `workflows`). احذف
> العلامة لإيقافه.
